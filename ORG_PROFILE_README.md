# Relay Labs

**Calm, dependable software for the places work actually happens —
operating theatres, clinics and frontline teams.**

Dublin, Ireland · [relaylabs.ie](https://relaylabs.ie) · [hello@relaylabs.ie](mailto:hello@relaylabs.ie)

</div>

We're an independent Irish product studio. We build focused tools with the people who
use them, ship carefully, and treat data protection as a design constraint — European
hosting, GDPR-native, and human-in-the-loop wherever software assists a decision.

## 🚧 In development

Product code lives in private repositories; each public repository below is that
project's overview and front door.

| | Project | Status |
|---|---------|--------|
| 🏥 | **[ORConnect](https://github.com/Relay-Labs-Ltd/orconnect)** — surgical theatre booking & perioperative platform. The operating day, in perfect order: consultant booking, theatre scheduling, pre-operative assessment, day of surgery and patient communications in one white-label system. | **Arriving 2027** · [site](https://orconnect.relaylabs.ie) |
| 🗓️ | **[Orla](https://github.com/Relay-Labs-Ltd/Orla)** — practice management for allied health clinics. Diary, clinical records, billing and a patient portal — with vacant slots refilled automatically from the waitlist by text. | In development |
| 💬 | **[9to5](https://github.com/Relay-Labs-Ltd/9to5)** — team communication for shift-based and frontline workers: messaging, tasks and shift scheduling in one place. | In development |
